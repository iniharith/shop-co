PENGURUS SUBLIMASI - SUBLIMATION MANAGER

Panduan mudah untuk Staf Sublimasi
Ikuti langkah dalam kotak di bawah sahaja.

Proses Kerja: Ikut Turutan Ini

1. PRINTING
Buka kerja. Semak ARTWORKS FOR PRINT. Muat turun dan cetak pesanan sublimasi.
↓
2. PRINT AWB
ARTWORKS telah dicetak. Cetak/semak AWB (label penghantaran) hanya apabila diminta oleh penyelia.
↓
3. DONE PRINT
Cetakan telah siap. Kerja sedang menunggu pembungkusan/penghantaran. Gunakan tab ini hanya untuk semak kerja siap atau cetak semula apabila diarahkan.
PENTING: Sebagai Staf Sublimasi, anda boleh melihat tiga tab ini tetapi tidak boleh memindahkan kerja ke langkah seterusnya. Maklumkan kepada Staf Production/Admin apabila cetakan siap.

Cara Muat Turun ARTWORKS untuk Cetakan

1. LOGIN
Buka laman Admin dan log masuk menggunakan akaun staf anda.
↓
2. BUKA “SUBLIMATION”
Anda akan melihat halaman Pengurus Sublimasi.
↓
3. KLIK “PRINTING”
Ini langkah pertama. Kerja di sini sedia untuk cetakan sublimasi.
↓
4. CARI FOLDER KERJA
Guna Search: taip Order ID, Task ID, atau nama fail.
↓
5. KLIK FOLDER
Semak Order/Task ID dan maklumat kerja di sebelah kanan.
↓
6. SEMAK LABEL FILE - AWB
Cari file yang betul sebelum mencetak.FOR PRINT = GUNA FILE INIAWB = GUNA FILE INI
↓
7. KLIK DOWNLOAD
Muat turun folder ZIP, kemudian cetak fail FOR PRINT yang telah diluluskan.
BERHENTI. JANGAN CETAK.
Jika fail salah, hilang, tidak jelas, atau tidak sama dengan pesanan. Maklumkan penyelia bersama Order/Task ID.

Fail Mana Boleh Dicetak?

FOR PRINT
YA
Ini fail akhir untuk pengeluaran.
AWB
YA
Guna untuk cetakan label penghantaran.
ATTACHMENT
TIDAK
File rujukan, bukan ARTWORKS cetakan.

Jika Tidak Jumpa Kerja

1. KOSONGKAN SEARCH
↓
2. SEMAK: PRINTING, KEMUDIAN PRINT AWB, KEMUDIAN DONE PRINT
Kerja bergerak melalui tab ini mengikut turutan ini.
↓
3. KLIK REFRESH
↓
4. MASIH TIDAK JUMPA?
Hantar Order/Task ID kepada penyelia.
PERANAN ANDA: Anda boleh melihat, menyemak, melihat pratonton, dan memuat turun fail.
Anda tidak boleh memuat naik, memadam, berkongsi, atau menukar status kerja. Minta bantuan Staf Production/Admin.
